支持与反馈

心图 - 十六人格图鉴 · iOS App 使用帮助

需要人工帮助？请发邮件到 aiyax@outlook.com，或在 GitHub Issues 提交问题。 请尽量附上：iOS 版本、App 版本、问题截图。

1. 怎么开始测试？

打开 App，在首页「选择测评深度」中选择版本：

  • 快速版 28 题：免费，约 4 分钟，适合第一次体验。
  • 高级版 50 题：¥12 一次性解锁，题目更多、报告更完整。
  • 专业版 98 题：包含在同一次 ¥12 解锁中，报告最长。

答完最后一题后点击「生成报告」，即可查看四维百分比和长文报告。

2. 高级版/专业版怎么解锁？

点击首页「高级版」或「专业版」卡片，会弹出付费页。确认价格 ¥12 后点击购买，使用 Apple ID 完成付款。一次购买永久解锁高级版 + 专业版，不会自动续费。

3. 买过了但 App 里没有解锁？

  1. 确认购买时使用的 Apple ID 与当前 App Store 登录的 Apple ID 一致。
  2. 打开付费页，点击底部的「恢复购买」。
  3. 保持网络连接，稍等几秒后重试。
  4. 仍无法恢复：发送邮件到 aiyax@outlook.com，附上购买截图和 App 版本。

4. 换手机/重装 App 后还能恢复吗？

可以。高级版/专业版是非消耗型内购，只要使用同一个 Apple ID，在新设备上打开付费页并点击「恢复购买」即可。测评历史和报告保存在本机，删除 App 或换设备后不会自动同步。

5. 怎么删除我的测评数据？

  • 在 App 的「我的」页面清空历史记录；或
  • 直接删除 App：系统会一并删除保存在本机的测评数据。

本 App 不在开发者服务器保存你的测评数据，因此没有额外的“云端删除”步骤。

6. 报告准吗？可以当心理诊断吗？

报告基于自我报告式偏好模型，适合用于自我探索、沟通和理解差异，不构成心理诊断、医疗建议或职业建议。结果会受当下状态、作答情境与自我认知影响，建议结合真实生活经验理解。如果你正经历持续的情绪困扰，请咨询专业心理或医疗人士。

7. 为什么 App 里的 MBTI 字样少了？

为避免与第三方商标混淆，App 使用「16 型人格」「四维偏好模型」等自有表述；测评内容与报告均为本项目原创。本 App 与 Myers-Briggs、16Personalities 没有关联。

8. 反馈 Bug 或建议

欢迎通过以下方式反馈：

  • 邮箱：aiyax@outlook.com
  • GitHub Issues：hasagee/personality-gacha-site/issues

如果是购买问题，请附上 Apple 的购买凭证截图；请勿发送 Apple ID 密码或完整银行卡号。

9. 隐私

本 App 不收集你的个人身份信息。详细说明见 隐私政策。
